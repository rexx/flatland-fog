# Flatland Fog 規劃

把 Edwin A. Abbott 的《Flatland: A Romance of Many Dimensions》（1884）做成可以邊讀邊玩的網頁：英文原文照章節呈現，書中的思想實驗與插圖改成可以操作的互動元件。

## 已定決策

| 項目 | 決定 |
|---|---|
| 正文 | 英文原文，取自 Standard Ebooks 版（原文為公有領域，Standard Ebooks 的成果以 CC0 釋出）。不放任何中文譯本 |
| 介面語言 | 全英文 |
| 技術 | 純靜態網頁，沒有建置步驟；函式庫從 cdnjs 載入並鎖定版本（three.js r128） |
| 頁面形式 | 每個互動元件是可以單獨開啟的頁面，閱讀頁用 `<iframe>` 嵌入；嵌入時隱藏元件自己的標題，高度自動配合內容 |
| 授權 | 程式碼 MIT；正文與插圖為公有領域 |
| 發布 | GitHub `rexx/flatland-fog`，public，開 GitHub Pages |

## 設計原則

- **黑白，直到顏色出現**：全站與互動元件都用灰階，跟原書的墨線插圖一致。§8–10（顏色的興起、Colour Bill、鎮壓）是全書第一次出現彩色的地方。介面與點綴不用彩色（也不用紫色當點綴）；§8–10 的互動元件照書中點名的顏色上色，紫色也照用。
- **霧的終點色與背景分開**：霧把遠處的點淡化成 `--fog`，不是背景色 `--paper`，這樣淡出的尖端在背景上仍看得出位置。
- **動畫優先，控制元件越少越好**：能用一段自動播放的動畫說清楚的，就不要給一排滑桿。動畫在第一次完整進入畫面時自動播放一次，播完停在最後一格，按鈕可以重播；系統開啟「減少動態效果」時不自動播放。
- **書中的時代觀念**：原書對女性和階級的描寫是 Abbott 的諷刺手法。§4、§5 相關元件的說明文字要點出這一點，避免被讀成認同。

## 章節與互動元件對應

優先度：**P1** 是第一批；**P2** 是第二批；**P3** 是有空再做。

| 節次 | 書中內容 | 互動元件 | 優先度 | 狀態 |
|---|---|---|---|---|
| §1 | 從正上方看桌上的圖形，眼睛降到桌面高度時變成一條線 | **coin-on-table**：一段自動動畫，視角從 90° 降到 0°，最後霧氣浮現 | P1 | 完成 |
| §2 | 雨從北方來，用來辨認方位；五邊形房屋，東邊女性門、西邊男性門；尖角房屋受限制 | **house-and-rain**：兩段場景，北方朝上的俯視圖。`?scene=north`：旅人在空曠平原上等雨，雨從北方落下後他才知道方位，走進城裡；五邊形房屋屋頂朝北擋雨，屋南沒有雨；街上遇到女士，他走南側、把北側讓給她；`?scene=law`：城裡與鄉下混著三角形、正方形、五邊形房屋，先標出 60°、90°、108° 的角，旅人撞上三角形的尖角；十一世紀三角形房屋被禁（兵營、火藥庫除外），約三百年後萬人以上城鎮改成五邊形，現在連鄉下也是，只剩偏遠處一間正方形 | P2 | 完成 |
| §3 | 正多邊形的兒子比父親多一條邊；等腰三角形的頂角每代增加半度，最多到 60° | **lineage**：兩段場景。`?scene=sons`：正方形、五邊形、六邊形一路往右，跳到十二邊、二十邊，最後與圓分不出來，下方標出紳士、貴族、Polygonal、祭司；`?scene=isosceles`：等腰三角形的兒子仍是等腰，好幾代不變，接著頂角每代加半度、底邊變寬、兩腰變短，到 60° 時經委員會認證為正三角形，離開父母（父親 59° 30′、母親是一條線）被沒有孩子的正三角形收養 | P2 | 完成 |
| §4 | 女性是線段，從端點看不見；公共場合必須持續發出 Peace-cry | **meeting-a-woman**：兩段場景，附平面國視野條。`?scene=needle`：女性在面前轉動，側面是一條線，眼端朝你時是很亮的點，背面朝你時是幾乎看不見的暗點；`?scene=street`：男人從背後走近一位女性三次：她不出聲時他只看到暗點、差點撞上；她持續發出 peace-cry 時他聽到而繞開；她左右擺動背部時，視野條上閃出短線 | P2 | 完成 |
| §5 | 靠聲音與觸摸辨認 | **feeling**：獨立元件，兩段場景。`?scene=touch`：正方形依序摸等腰、正三角形、正方形、五邊形、十邊與十二邊、二十邊與二十四邊的一個角，下方角度尺標出各階級的角，越高階越難分；`?scene=ancestor`：祖父的故事，59° 30′ 的祖先被多邊形觸摸時猛然一動刺穿對方，家族退到 58°，每代加半度，五代後才回到 60° | P2 | 完成 |
| §6 | 靠霧中的明暗辨認；商人（正三角形）與醫生（五邊形）、以一條邊正對觀察者的六邊形孫子 | **recognition-by-sight**：嵌在正文的動畫，三個人物依序從霧中走近；**recognition-game**：獨立頁面，探索與考試兩個模式，從動畫下方連過去 | P1 | 完成 |
| §7 | 不規則圖形 | **irregular**：三段場景，各嵌在對應段落之後。`?scene=groping`：正方形摸五邊形的一個角就認出對方；換成「三角前、多邊後」的人，第一個角 60° 像三角形，只好一個角一個角摸下去，九個角各不相同；`?scene=door`：三位商人走進你家門，第三位身後拖著對角線約 12.6 吋的平行四邊形，卡在門口；`?scene=impostor`：同一個人以多邊形那面朝前走進店裡，霧中看起來像紳士，轉身後露出尖角。辨認遊戲也加入這個圖形（探索與測驗） | P3 | 完成 |
| §8 | Chromatistes 替自己上色，流行擴散到全國，只剩女性與祭司沒有顏色；閱兵 | **colour-revolt**：三段場景，各嵌在對應段落之後。`?scene=chromatistes`：一片灰線風景，Chromatistes 依序替房屋、奴隸、父親、兒子、自己上色，接著轉一圈，上色與未上色的視野條並排；`?scene=spread`：街上行人排成一列，由左到右直線走過觀察者面前，從霧中走出再走回霧裡，畫面上同時約五人；新走進來的人穿著當時的流行，已在街上的同階級者稍後跟進，依書中時間表（一週、一兩個月、一年、兩代）推進，最後只剩女性與祭司是灰的；`?scene=review`：各兵種在指揮官面前排成一列，由左到右直線行進，同一兵種朝同一個方向，兩端的人在視野中是斜的，Isosceles 轉身，黑色底邊換成橘紫兩邊，接著紅白藍的正三角形、四色的正方形砲兵與朱紅砲、五色六色的五邊形與六邊形。後兩段附平面國視野條。三段的霧都依圖形大小換算濃度（chromatistes 與 §6 相同，後兩段略淡），所以人物都站在差不多的距離，每個人在視野條上各有一段亮暗漸層 | P2 | 完成 |
| §9–10 | Colour Bill、鎮壓 | **colour-bill**：嵌在 §9 插圖 5 之後。女性與祭司並排，先以灰階靠明暗分辨；依法案塗上前紅後綠後，兩者都成了一條半紅半綠的線，女性再學會讓兩端變暗，就幾乎分不出來 | P2 | 完成 |
| §13 | 直線國，國王只看得到一個點 | **lineland**：四段場景，各嵌在對應段落之後。`?scene=dream`：線段（男人）與亮點（女人）在同一條直線上一起來回移動並發出啁啾，接著停下；挑出一位直線國居民，下方兩格是他兩端的眼睛，各只看到一個點，男人女人看起來一樣，只能靠聲音分辨；`?scene=voice`：正方形先生在線外說話，國王只感覺聲音打在身側，接著正方形把一個角伸進直線，國王的右眼才看到一個點；`?scene=neighbours`：國王與兩位妻子之間隔著六個男人，他往前擠被鄰居擋住，大家晃動但順序永不改變；`?scene=chorus`：數到一百零一拍的劇烈舞動，第五十一拍停下齊唱；一位男人的低音與男高音和遠方兩位妻子的女低音、女高音逐週靠近和聲，最後三人以聲音結合，生下一男二女 | P2 | 完成 |
| §14、§16 | 正方形先生走出直線國；球體升出平面國，截面縮成一點後消失 | **passing-through**：兩段截面動畫，`?scene=lineland` 嵌在 §14、`?scene=sphere` 嵌在 §16 | P1 | 完成 |
| §18 | 從空間國俯視平面國，房屋內部一覽無遺 | **view-from-above**：視角從平面升到上方，屋內家人逐一現形，最後拉遠看到整座城市 | P1 | 完成 |
| §19 | 點→線→正方形→立方體，再推到四維 | **dimension-ladder**：兩段場景。`?scene=cube` 嵌在插圖 10 之後：球體把正方形卡片一張張疊成立方體，再換成有光影的實心立方體，正方形先生仍看成平面。`?scene=analogy` 嵌在「8 bounding Cubes」那段之後：點移動成線、線移動成正方形、正方形移動成立方體，每步留下一串軌跡；最後立方體往「新方向」移動，畫成透視裡縮小的影子，成為立方體套立方體。下方表格逐步填出端點 1、2、4、8、16 與邊界 2、4、6、8 | P2 | 完成 |
| §20 | 點國 | **pointland**：三段場景，各嵌在對應段落之後。`?scene=approach`：球體與正方形飄向一個極小的亮點，它的嗡嗡聲只傳得到二十個對角線遠，進了這個範圍才聽見；`?scene=soliloquy`：點國裡只有它自己，想的、說的、聽到的繞一圈回到自己；`?scene=harangue`：正方形大聲斥責它，聲音傳到之後點反而更亮，下方顯示它聽到的話變成「Its own thought」 | P3 | 完成 |

## 共用模組（`shared/`）

| 檔案 | 內容 |
|---|---|
| `theme.css` | 灰階配色、字型、按鈕與面板樣式；深色與淺色兩套 |
| `reader.css`、`reader.js` | 閱讀頁與目錄頁樣式；依互動元件回報的高度調整嵌入框 |
| `embed.js` | 互動元件在嵌入框內時隱藏標題，並回報自己的高度 |
| `player.js` | 動畫的播放控制：第一次完整進入畫面時自動播放一次、按鈕暫停與重播、`?t=` 停在指定時間點；字幕依閱讀速度逐字淡入，動作結束後停留到讀得完；‹ › 按鈕切換上一句、下一句；框框底部的時間軸可以拖到任一時間點並停在那裡 |
| `geometry.js` | 圖形頂點、射線與邊的交點、最近點、視角寬度、霧中亮度 |
| `canvas.js` | 一維霧中畫面、亮度曲線、俯視圖、旋轉曲線的 2D 繪圖 |
| `slab3d.js` | 把平面圖形做成薄片的 3D 視圖，含 `ink`（黑白）與 `colour` 兩種配色 |
